# /api is closed, with one exception: /api/public/ holds the open data the
# /ai-crawlers page publishes under CC BY and asks to be cited — the crawler
# reference, the robots.txt measurement, the per-site rows and the OpenAPI
# description. `Disallow: /api` was blocking every crawler from exactly the
# URLs our own Dataset markup points at, Googlebot and GPTBot included. A
# longer Allow beats a shorter Disallow (RFC 9309 2.2.2), so the line below,
# repeated in each group, opens /api/public/ and nothing else under /api.
# lib/ai-crawlers/__qa__/ai-crawler-access.qa.ts checks this with the same
# matcher the public checker runs.

User-agent: *
Allow: /
Disallow: /admin
Disallow: /dashboard
Disallow: /api
Allow: /api/public/
