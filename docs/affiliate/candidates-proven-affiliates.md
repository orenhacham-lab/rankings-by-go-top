# Proven SEO-tool affiliates (reverse-engineered from competitor rosters)

Run date: 2026-11-12. **Nobody here has been contacted.** No affiliate link was clicked — every URL below was read as text off an opened page.

## Method

Rather than searching for "SEO bloggers", this run reverse-engineered the affiliate rosters of competing recurring SEO tools (Surfer SEO, SE Ranking, Serpstat, Mangools/KWFinder, Writesonic, Koala, plus the rank trackers) by hunting for:

1. **Literal tracking parameters** on vendor domains — `?fp_ref=`, `?ref=`, `?via=`, `?ga=`, `?aff=`. This is the strongest possible evidence: the affiliate's own ID is in the URL.
2. **Coupon codes named after the publisher** (`wittysparks_discount`, `99signals2023`, `bloggingx25`, `KRIP20`, `COUPON15`). A vendor only mints a branded code for an affiliate it has a relationship with.
3. **Cloaked redirect rosters** — `/go/<vendor>`, `/recommends/<vendor>`, `go.<domain>/<vendor>`. The *set* of vendors in the roster shows how many competing programmes one person is already monetising.

Ranking is by strength of evidence, not by audience size.

## Which roster was the richest hunting ground

**Surfer SEO, clearly.** Nine of the 22 (rows 1, 2, 5, 6, 10, 11, 16, and the Surfer funnels on 14/18) carry a Surfer affiliate link, and Surfer produced the only *literal* vendor-side affiliate ID in the whole run (`?fp_ref=john44`). Surfer's programme appears to run on FirstPromoter with cloaked `get.surferseo.com/<hash>` links, which makes its affiliates easy to fingerprint.

**Mangools/KWFinder is second and is the better fit commercially.** Six properties (rows 5, 9, 12, 13, 15, 20, 21) promote it, and it is the programme that mints *brand-named coupon codes* — `bloggingx25`, `MasterBlogging`, `99signals2023`-style codes. Anyone holding one of those has a managed relationship and a negotiated offer, which is exactly the publisher who can slot in a fifth tool.

**Serpstat punched above its weight**: it was the only programme where affiliate IDs sat in plain URLs twice (`?ref=98290`, `?ref=848686`), making it the fastest roster to enumerate.

**The AI-visibility tools (Profound, Peec AI, Otterly) have essentially no affiliate layer yet.** Every comparison page on that topic turned out to be vendor content — SE Ranking, Writesonic, Waikay, Stork, Inithouse writing about their own competitors. There is no roster to reverse-engineer there, which is itself useful: Go Top SEO's AI-visibility angle has no incumbent affiliate competition.
